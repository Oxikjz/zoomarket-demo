# Зоомаркет Демо

Демонстрационный сайт-витрина сети зоомагазинов: каталог товаров с ценами и наличием по магазинам, поиск с поддержкой русских форм слов и опечаток, бонусная карта, страницы «О компании», «Вакансии», правовая информация.

Сайт статический: HTML, CSS и JS без фреймворков и без базы данных. Товары и наличие читаются из двух JSON-файлов.

Все данные вымышлены: названия, бренды, цены, реквизиты, адреса, телефоны и почта. Тексты политики конфиденциальности и правовой информации демонстрационные и не являются юридическими документами.

## Запуск

```
python3 tools/demo_data.py          # сгенерировать каталог и наличие
python3 -m http.server 8090         # открыть http://127.0.0.1:8090
```

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `catalog.html`, `about.html`, `vacancies.html`, `legal.html`, `privacy.html` | страницы |
| `assets/js/site.js` | данные магазинов (`ZOO.stores`), питомцев, бонусной скидки |
| `assets/js/search.js` | загрузка данных и умный поиск |
| `assets/js/catalog.js` | фильтры, ленты разделов, карточки товаров |
| `assets/css/` | стили |
| `data/` | `catalog.json`, `stock.json` (наличие по магазинам битовой маской), `bonus.json` |
| `tools/demo_data.py` | генератор вымышленных данных |

Логотип, картинки категорий и главного экрана в этой версии заглушки, нарисованные скриптом. Фото в карточках товаров взяты с бесплатных фотостоков (Unsplash, Pexels).
